# Ms. Bee & Co. - Demo Landing Page

This is a frontend demo for Ms. Bee & Co.

## Project Structure

```
├── src/
│   ├── assets/
│   │   └── images/
│   │       ├── ms-bee-product-range.jpg
│   │       ├── toilet-cleaner-instagram.jpg
│   │       ├── hand-soap-instagram.jpg
│   │       ├── floor-cleaner-instagram.jpg
│   │       └── antiseptic-cleaner-instagram.jpg
│   ├── css/
│   │   └── style.css    # Custom styles
│   ├── js/
│   │   ├── main.js      # Main interactivity
│   │   └── security.js
│   └── index.html       # Main HTML entry point
├── .gitignore
└── README.md
```

## How to Run
Open the project root with Live Server or another static server. The root `index.html` forwards to `src/index.html`, so opening the server URL displays the site instead of a directory listing.

## Product imagery
The hero uses a product-range photo; several product cards use individual product creatives from Ms. Bee's public social profile. The site links to the brand's Instagram and Facebook profiles for updates and product enquiries. Replace the demo imagery with approved product photography if the range or packaging changes.

## Technologies Used
- HTML5
- Tailwind CSS (via CDN)
- Vanilla JavaScript
